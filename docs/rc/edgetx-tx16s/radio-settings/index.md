Розділ **Settings** пульта містить усі опції для налаштування вашого пульта. У верхній частині сторінки ви побачите іконки, які після вибору переведуть вас на різні сторінки налаштувань пульта. Екраном за замовчуванням для налаштувань пульта є екран [Tools ](tools.md).

Іконки у верхній частині екрана налаштувань пульта включають (по порядку зліва направо):

* [Tools](tools.md)
* [SD Card](sd-card.md)
* [Radio Setup](radio-setup/)
* [Themes](themes.md)
* [Global Functions](global-functions.md)
* [Trainer](../model-settings/model-setup/trainer.md)
* [Hardware](hardware.md)
* [Version](version.md)
