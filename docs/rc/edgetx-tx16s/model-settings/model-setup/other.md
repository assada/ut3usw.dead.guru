### ADC Filter

Вмикає/вимикає ADC Filter для цієї моделі. Опція _**global**_ використовуватиме значення, вказане в налаштуваннях пульта, яке увімкнене за замовчуванням.

:::info
ADC Filter — це фільтр для пропорційних каналів (стіків, потенціометрів, слайдерів), який згладжує дрібні швидкі рухи, що виникають через шум в електроніці системи. Зазвичай цей фільтр **має бути вимкнений** для моделей з польотними контролерами.
:::

### **Beep when centered**

Дозволяє вмикати / вимикати функцію звукового сигналу по центру для окремих стіків, потенціометрів та слайдерів шляхом їх вибору (підсвічуються жовтим).
