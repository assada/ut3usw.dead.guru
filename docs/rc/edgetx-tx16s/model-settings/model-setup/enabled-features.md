Розділ **Enabled Features** у **Model Setup** дозволяє налаштувати, які вкладки будуть видимими в розділах налаштувань пульта та налаштувань обраної моделі в EdgeTX. Ви можете вибрати наступні опції:

* **Global** — якщо вибрано, вкладка набуде глобального значення, налаштованого в розділі **Enabled Features** у **Radio Setup**. Налаштоване глобальне значення відображатиметься поруч із цією опцією.
* **On** — якщо вибрано, ця вкладка буде видимою, коли завантажено цю модель.
* **Off** — якщо вибрано, ця вкладка не буде видимою, коли завантажено цю модель.

:::info
_**Примітка:**_ Вимкнення вкладки лише приховує її та не змінює елементи, які вже були налаштовані на цій вкладці.

**ВИНЯТОК:** Вимкнення вкладки Global / Special Functions призведе до вимкнення налаштованих глобальних / спеціальних функцій для цієї моделі.
:::
